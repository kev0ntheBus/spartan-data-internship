# Syllabus

## Program Overview

The Spartan Data Internship is a 10-week asynchronous training program beginning Monday, June 1, 2026. Week 0 is preparation before the start date.

## Weekly Syllabus

| Week | Date Range | Weekly Goal | Skills Covered | Expected Deliverables | Review Checkpoint | End-of-Week Assessment | Workload | Guided vs Open-Ended |
|---:|---|---|---|---|---|---|---|---|
| 0 | Before Jun 1 | Prepare environment | Python 3.12, `.venv`, VS Code, Jupyter, Git | environment checks, smoke tests, notes | Can run scripts and notebooks | Setup checklist | 3-5 hrs | 100% guided |
| 1 | Jun 1-Jun 7 | Rebuild fundamentals | Python basics, SQL basics, pandas intro, Git habit | daily scripts, SQL files, reflections | Correct syntax and repetition | Week 1 review | 10-15 hrs | 90% guided |
| 2 | Jun 8-Jun 14 | Transition to analyst practice | pandas filtering, cleaning, joins, aggregations, EDA | guided exercises plus small analysis choices | Explain why each filter/grouping was used | Short EDA review | 10-15 hrs | 50% guided |
| 3 | Jun 15-Jun 21 | Start project-based EDA | data inspection, missing values, summary stats, chart choice | mini EDA project draft | Findings must be supported by evidence | EDA critique | 12-16 hrs | 30% guided |
| 4 | Jun 22-Jun 28 | Add statistics foundations | distributions, sampling, correlation, uncertainty | stats notes, analysis notebook | Avoid overclaiming | Interpretation review | 12-16 hrs | 25% guided |
| 5 | Jun 29-Jul 5 | Introduce machine learning | train/test split, regression, classification, metrics | simple ML notebook and report | Metrics interpreted correctly | ML foundations check | 12-18 hrs | 25% guided |
| 6 | Jul 6-Jul 12 | Build data engineering basics | files, JSON, APIs, ETL, scripts | small repeatable pipeline | Can rerun from clean inputs | Pipeline review | 12-18 hrs | 20% guided |
| 7 | Jul 13-Jul 19 | Add database workflow | PostgreSQL concepts, schemas, joins, loading data | SQL portfolio draft | Queries are readable and testable | SQL review | 12-18 hrs | 20% guided |
| 8 | Jul 20-Jul 26 | Build portfolio projects | project planning, README writing, reproducibility | project drafts | Project story is clear | Portfolio checkpoint | 12-20 hrs | 15% guided |
| 9 | Jul 27-Aug 2 | Polish and review | cleanup, charts, reports, code review | improved project artifacts | Findings and limitations are clear | Mock review | 12-20 hrs | 10% guided |
| 10 | Aug 3-Aug 9 | Final presentation readiness | communication, interview prep, repo cleanup | final reports, project READMEs, resume bullets | Can explain each project | Final review | 8-15 hrs | mostly independent |

## Weekly Expectations

Every week should include:

- code practice
- SQL practice
- notes or concept summaries
- reflection
- Git commits
- review against `REVIEW_RUBRIC.md`

## Assessment Pattern

- **Week 1:** correctness, repetition, and basic confidence
- **Week 2:** choice-making and simple explanations
- **Week 3+:** analysis quality, reproducibility, and independence
