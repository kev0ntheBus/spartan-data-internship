# Glossary

## Python

**Variable:** a name that stores a value.

**Function:** reusable code that performs a task.

**List:** ordered collection of values.

**Dictionary:** collection of key-value pairs.

**Tuple:** ordered collection that is usually not changed after creation.

**Set:** unordered collection of unique values.

**Loop:** code that repeats.

**Conditional:** logic that runs only when a condition is true or false.

**Module:** a Python file or library that can be imported.

**Package:** a collection of modules.

**Virtual Environment:** isolated Python environment for a project.

**Notebook:** interactive `.ipynb` file with code and markdown cells.

**Script:** `.py` file intended to run as a program.

## pandas

**DataFrame:** table-like pandas object with rows and columns.

**Series:** one-dimensional pandas object, often a single DataFrame column.

## SQL

**SQL Query:** instruction written in SQL to retrieve or transform data.

**Table:** database object with rows and columns.

**Row:** one record in a table.

**Column:** one field in a table.

**Primary Key:** column or columns that uniquely identify rows.

**Foreign Key:** column that connects one table to another.

**Aggregation:** calculation across multiple rows, such as `COUNT`, `AVG`, or `SUM`.

**Join:** operation that combines rows from related tables.

## Data Science

**Model:** algorithm trained to make predictions or find patterns.

**Feature:** input variable used by a model.

**Target:** value a model is trying to predict.

## Data Engineering

**Pipeline:** repeatable process for moving or transforming data.

**ETL:** extract, transform, load.

**API:** interface that lets programs communicate with another service or application.
