# Roadmap

## Start Date

**Current planned start date:** Monday, June 1, 2026
**Program style:** asynchronous with fixed lesson order

Date labels are planning aids. If the start date changes, keep the lesson order and shift the dates forward.

## Phase 0: Week 0 Preparation

**Timing:** Before June 1, 2026

Focus:

- Install and verify Python 3.12.
- Create and activate `.venv`.
- Open the repo in VS Code.
- Install dependencies from `requirements.txt`.
- Register the Jupyter kernel.
- Confirm Git and GitHub workflow.
- Run pandas and matplotlib smoke tests.

Exit criteria:

- `python --version` works in the activated environment.
- `pip install -r requirements.txt` completes.
- Jupyter sees the `Python 3.12 - SpartanDataCamp` kernel.
- `week0/pandas_test.py` and `week0/mini_eda.py` run.
- `git status` is understood before committing.

## Phase 1: Week 1 Foundations Reboot

**Dates:** June 1-7, 2026

Focus:

- Python basics
- SQL basics
- pandas basics
- Git/GitHub habit
- Jupyter and VS Code workflow
- daily reflections
- high repetition and correct fundamentals

The first week should feel slow on purpose. Repeat variables, lists, dictionaries, loops, conditionals, functions, and basic SQL until the patterns are familiar.

## Phase 2: Week 2 Intermediate Analyst Transition

**Dates:** June 8-14, 2026

Focus:

- EDA workflow
- pandas filtering and cleaning
- SQL joins
- aggregations
- basic visualizations
- small open-ended analysis decisions

Week 2 should be about 50% guided and 50% open-ended. You still get scaffolding, but you start explaining your choices.

## Phase 3: Weeks 3-5 Real Data Science

**Dates:** June 15-July 5, 2026

Focus:

- statistics foundations
- exploratory analysis
- regression
- classification
- model evaluation
- feature engineering
- communicating findings

Work becomes more open-ended. You should write assumptions, inspect data quality, compare approaches, and explain tradeoffs.

## Phase 4: Weeks 5-7 Data Engineering Foundations

**Dates:** June 29-July 19, 2026

Focus:

- ETL concepts
- PostgreSQL foundations
- Python scripts
- APIs
- JSON
- pipelines
- automation
- reproducible project structure

Week 5 overlaps as a transition from analysis into repeatable data workflows.

## Phase 5: Weeks 7-10 Portfolio and Job Readiness

**Dates:** July 13-August 9, 2026

Focus:

- polished GitHub projects
- SQL portfolio queries
- dashboards or visual reports
- machine learning project writeups
- resume and LinkedIn support
- interview prep
- project review and cleanup

The final phase should produce fewer files and better artifacts. The goal is not volume. The goal is work that can be explained clearly.
