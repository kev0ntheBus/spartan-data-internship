# Week 0: Preparation

**Timing:** Complete before Monday, June 1, 2026.

Week 0 confirms that the environment works before formal training begins.

## Objectives

- Confirm Python 3.12 is installed.
- Create and activate `.venv`.
- Install project dependencies.
- Register the Jupyter kernel.
- Run basic pandas and matplotlib smoke tests.
- Confirm Git/GitHub workflow.

## Files

- `environment_check.py`: checks Python version and core packages
- `pandas_test.py`: confirms pandas can read and summarize data
- `mini_day0.csv`: tiny starter dataset
- `mini_eda.py`: tiny EDA smoke test
- `notes.md`: setup notes and checklist

## Completion Checklist

- [ ] `.venv` activates in PowerShell.
