# Week 6: Data Engineering Foundations

**Dates:** July 6-12, 2026  
**Mode:** practical scripts, repeatable workflows, and validation

Week 6 starts building data engineering habits: repeatable scripts, clear inputs and outputs, and simple validation checks.

## Weekly Focus

- ETL concepts
- file paths
- JSON
- reusable Python scripts
- simple data validation
- pipeline thinking
- reproducibility

## Expected Deliverables

- one small ETL-style script
- input/output notes
- validation checklist
- weekly review

## Review Questions

- Can this script run twice and produce the same kind of output?
- Where does the data come from?
- What validation checks are needed?
- What should happen when input data is missing or malformed?

## Folders

- `assignments/`: ETL and scripting practice
- `pipelines/`: small pipeline drafts
- `notes/`: data engineering notes
