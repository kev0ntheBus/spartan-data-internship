# Week 8: Portfolio Project Buildout

**Dates:** July 20-26, 2026  
**Mode:** project-based and independent

Week 8 shifts from lessons to building portfolio artifacts.

## Weekly Focus

- project README quality
- reproducible notebooks and scripts
- chart selection
- SQL project polish
- analysis writeups
- limitations and next steps

## Expected Deliverables

- at least one project draft improved
- project README updated
- report draft in `reports/project_reports/`
- weekly review

## Review Questions

- Can someone understand the project from the README?
- Can the work be rerun?
- Are findings supported by evidence?
- Are limitations honest and specific?

## Folders

- `project_work/`: active Week 8 project notes
- `review/`: critique notes and fixes
- `notes/`: portfolio lessons
