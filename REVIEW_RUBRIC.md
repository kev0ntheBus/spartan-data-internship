# Review Rubric

Use this rubric for daily reviews, weekly checkpoints, and project feedback.

## Categories

| Category | Week 1 Standard | Week 2 Standard | Week 3+ Standard |
|---|---|---|---|
| Correctness | Code runs and basic syntax is correct | Logic handles simple variations | Work is accurate, tested, and defensible |
| Readability | Clear names and simple formatting | Consistent formatting and comments where useful | Code is organized for review and reuse |
| Repetition / Skill Retention | Repeated drills are completed | Patterns are used with less prompting | Skills transfer to new problems |
| Documentation Quality | Daily notes are complete | Notes explain choices | Documentation supports reproduction |
| Git Hygiene | Commits happen daily | Commits are scoped and named clearly | History supports project review |
| Interpretation / Analysis | Basic observations are written | Claims connect to data | Findings include limits and tradeoffs |
| Independence | Follows guided steps | Solves small open-ended tasks | Plans, debugs, and improves work independently |
| Professionalism | Work is organized and complete | Work is reviewable | Work is portfolio-ready |

## Week 1 Emphasis

Week 1 is graded on effort, repetition, and correct fundamentals. The goal is not clever code. The goal is reliable basics.

Strong Week 1 work:

- repeats exercises without skipping steps
- uses readable variable names
- runs scripts before committing
- writes honest reflections
- asks clear questions

## Week 2 Emphasis

Week 2 begins evaluating problem-solving. You should explain filtering choices, joins, aggregations, and simple analysis decisions.

## Week 3+ Emphasis

Week 3 and later evaluate code design, analysis quality, reproducibility, and autonomy.

Strong later work:

- states assumptions
- checks data quality
- explains methods
- avoids unsupported claims
- includes limitations and next steps
