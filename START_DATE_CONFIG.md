## Reconfiguring the Start Date

This bootcamp is asynchronous. The date labels help with planning, but the learning logic depends on lesson sequence, not the calendar.

If the start date changes, update START_DATE_CONFIG.md first, then shift all weekly and daily date labels forward while preserving the same sequence of lessons.

Example reasons to change the start date:

- delaying until after relocating to Colombia
- needing more time for environment setup
- pausing for work, travel, or personal scheduling

## How to Update the Roadmap

1. Update the placeholder fields at the top of this file.
2. Choose the new Monday start date.
3. Keep Week 1 Day 1 as the first formal lesson.
4. Shift every week and daily README date forward by the same number of days.
5. Do not change lesson order unless the curriculum itself changes.
6. Update `README.md`, `ROADMAP.md`, and `SYLLABUS.md` date labels.

## Rule

- Week 2: analyst transition
