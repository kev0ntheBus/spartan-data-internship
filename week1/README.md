# Week 1: Foundations Reboot

**Dates:** June 1-7, 2026
**Mode:** highly guided, high repetition

Week 1 rebuilds the basics from zero. The goal is not speed. The goal is confidence through repetition.

## Weekly Goals

- Understand Python variables, data types, lists, dictionaries, loops, conditionals, and functions.
- Practice basic file I/O.
- Learn basic SQL reading and query structure.
- Start pandas with DataFrames, Series, reading CSVs, filtering, sorting, and adding columns.
- Write daily reflections.
- Commit work consistently.

## Week 1 Rules

- Repeat simple patterns until they feel familiar.
- Prefer clear code over clever code.
- Write SQL even if there is no live database yet.
- Commit after completed work, not every tiny edit.
- Use reflections to track confusion honestly.

## End-of-Week Checkpoint

By the end of Week 1, you should be able to:

- explain what a variable is
- write simple loops and functions
- read a tiny file
- write basic SQL queries
- load a CSV with pandas
- describe a DataFrame and Series
- make a clean daily commit
